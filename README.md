## 👋 About Me

I work where **technology, data and business strategy** meet. I build machine-learning models, data pipelines and full-stack web applications, and I turn the results into dashboards and KPIs that management teams act on.

- 🔭 Currently building **analytics and decision-support systems** for the cooperative finance sector
- 🎓 Trained through **10 Academy — Kifiya AI Mastery (KAIM)**: an intensive program in ML engineering, data engineering and financial analytics
- 🏢 Building with **Underdog Lab**: technology for underserved communities
- 🌱 Learning: MLOps, LLM applications and cloud data platforms
- 🤝 Open to: data science collaborations, open-source contributions and analytics-strategy consulting
- ⚡ Motto: *“Data builds insight, strategy drives impact, and technology transforms communities.”*
